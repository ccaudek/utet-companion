Introduzione

Lo studio di Gould et al. (2025) ha mostrato un risultato sorprendente: 174 team di ricerca, analizzando gli stessi dati per rispondere alla stessa domanda, hanno prodotto conclusioni che variavano da effetti fortemente negativi a effetti positivi. Questa variabilità non era dovuta a errori o incompetenza, ma alle legittime scelte metodologiche che ogni ricercatore compie durante l’analisi.

Questo fenomeno è noto come “gradi di libertà del ricercatore” (researcher degrees of freedom) e rappresenta una delle cause principali della crisi di replicabilità. In questo capitolo esploreremo computazionalmente come nascono queste divergenze e quali strategie possono mitigarle.

6.1 Il Problema: Uno Spazio Analitico Vasto

Ogni analisi statistica richiede una serie di decisioni:

  • Come gestire gli outlier? (escludere, winsorizzare, mantenere)
  • Quali covariate includere? (età, genere, SES, tutte, nessuna)
  • Quale modello usare? (regressione, ANOVA, mixed effects)
  • Come definire la variabile dipendente? (trasformata, grezza, standardizzata)
  • Quali criteri di esclusione applicare? (missing data, attention checks)

Se ogni decisione ha 2-3 opzioni, con 5 decisioni si generano \(3^5 = 243\) possibili analisi. Con 10 decisioni, sono 59.049 analisi diverse. Ogni studio pubblicato è una singola traiettoria in questo vasto spazio.

6.2 Simulazione 1: Creare un Dataset “Ambiguo”

Creiamo un dataset che simula una situazione realistica: un effetto piccolo ma reale, con outlier, missing data, e covariate correlate.

  )

6.3.2 Implementazione delle scelte

# Funzione per preparare i dati secondo le scelte
prepare_data <- function(data, outlier_method, missing_method, transform_method) {
  df <- data
  
 # 1. Gestione outlier (prima di altri preprocessing)
  if (outlier_method == "remove_3sd") {
    # Calcola su dati non-missing
    valid_outcomes <- df$outcome[!is.na(df$outcome)]
    m <- mean(valid_outcomes)
    s <- sd(valid_outcomes)
    df <- df |> 
      filter(is.na(outcome) | (outcome > m - 3*s & outcome < m + 3*s))
  } else if (outlier_method == "winsorize") {
    valid_outcomes <- df$outcome[!is.na(df$outcome)]
    lower <- quantile(valid_outcomes, 0.05)
    upper <- quantile(valid_outcomes, 0.95)
    df <- df |>
      mutate(outcome = pmax(pmin(outcome, upper), lower))
  }
  
  # 2. Gestione missing
  if (missing_method == "listwise") {
    df <- df |> filter(!is.na(outcome))
  } else if (missing_method == "mean_imputation") {
    m <- mean(df$outcome, na.rm = TRUE)
    df <- df |> mutate(outcome = ifelse(is.na(outcome), m, outcome))
  }
  
  # 3. Trasformazione
  if (transform_method == "log") {
    # Shift per evitare log di valori negativi
    min_val <- min(df$outcome)
    df <- df |> mutate(outcome = log(outcome - min_val + 1))
  } else if (transform_method == "standardized") {
    df <- df |> mutate(outcome = scale(outcome)[,1])
  }
  
  return(df)
}

# Funzione per eseguire l'analisi
run_analysis <- function(data, covariate_set) {
  formula <- switch(covariate_set,
    "none" = outcome ~ condition,
    "age" = outcome ~ condition + age,
    "age_gender" = outcome ~ condition + age + gender,
    "all" = outcome ~ condition + age + gender + education
  )
  
  model <- lm(formula, data = data)
  
  # Estrai coefficiente del treatment
  tidy_model <- tidy(model, conf.int = TRUE)
  treatment_row <- tidy_model |> filter(term == "conditiontreatment")
  
  if (nrow(treatment_row) == 0) return(NULL)
  
  tibble(
    estimate = treatment_row$estimate,
    std_error = treatment_row$std.error,
    p_value = treatment_row$p.value,
    conf_low = treatment_row$conf.low,
    conf_high = treatment_row$conf.high,
    n_used = nrow(data)
  )
}

6.9 Riflessioni Conclusive

Le simulazioni di questo capitolo dimostrano che:

  1. Lo spazio analitico è vasto: Anche con poche decisioni, esistono decine di analisi possibili.
  2. Scelte ragionevoli divergono: Ricercatori competenti, usando metodi giustificabili, arrivano a conclusioni opposte.
  3. Alcune scelte pesano più di altre: La gestione degli outlier e le trasformazioni hanno spesso l’impatto maggiore.
  4. La pre-registrazione aiuta ma non basta: Fissa una traiettoria, ma non garantisce che sia quella “giusta”.
  5. Il multiverse aumenta la trasparenza: Mostrare l’intera distribuzione delle conclusioni possibili è più onesto di un singolo risultato.

  control <- data |> filter(condition == "control") |> pull(outcome)
  treatment <- data |> filter(condition == "treatment") |> pull(outcome)

## Introduzione {.unnumbered}

Lo studio di @gould2025same ha mostrato un risultato sorprendente: 174 team di ricerca, analizzando gli **stessi dati** per rispondere alla **stessa domanda**, hanno prodotto conclusioni che variavano da effetti fortemente negativi a effetti positivi. Questa variabilità non era dovuta a errori o incompetenza, ma alle **legittime scelte metodologiche** che ogni ricercatore compie durante l'analisi.

Questo fenomeno è noto come **"gradi di libertà del ricercatore"** (*researcher degrees of freedom*) e rappresenta una delle cause principali della crisi di replicabilità. In questo capitolo esploreremo computazionalmente come nascono queste divergenze e quali strategie possono mitigarle.

## Il Problema: Uno Spazio Analitico Vasto

Ogni analisi statistica richiede una serie di decisioni:

- Come gestire gli **outlier**? (escludere, winsorizzare, mantenere)
- Quali **covariate** includere? (età, genere, SES, tutte, nessuna)
- Quale **modello** usare? (regressione, ANOVA, mixed effects)
- Come definire la **variabile dipendente**? (trasformata, grezza, standardizzata)
- Quali **criteri di esclusione** applicare? (missing data, attention checks)

Se ogni decisione ha 2-3 opzioni, con 5 decisioni si generano $3^5 = 243$ possibili analisi. Con 10 decisioni, sono **59.049** analisi diverse. Ogni studio pubblicato è una singola traiettoria in questo vasto spazio.

```{r}
# Funzione per preparare i dati secondo le scelte
prepare_data <- function(data, outlier_method, missing_method, transform_method) {
  df <- data
  
 # 1. Gestione outlier (prima di altri preprocessing)
  if (outlier_method == "remove_3sd") {
    # Calcola su dati non-missing
    valid_outcomes <- df$outcome[!is.na(df$outcome)]
    m <- mean(valid_outcomes)
    s <- sd(valid_outcomes)
    df <- df |> 
      filter(is.na(outcome) | (outcome > m - 3*s & outcome < m + 3*s))
  } else if (outlier_method == "winsorize") {
    valid_outcomes <- df$outcome[!is.na(df$outcome)]
    lower <- quantile(valid_outcomes, 0.05)
    upper <- quantile(valid_outcomes, 0.95)
    df <- df |>
      mutate(outcome = pmax(pmin(outcome, upper), lower))
  }
  
  # 2. Gestione missing
  if (missing_method == "listwise") {
    df <- df |> filter(!is.na(outcome))
  } else if (missing_method == "mean_imputation") {
    m <- mean(df$outcome, na.rm = TRUE)
    df <- df |> mutate(outcome = ifelse(is.na(outcome), m, outcome))
  }
  
  # 3. Trasformazione
  if (transform_method == "log") {
    # Shift per evitare log di valori negativi
    min_val <- min(df$outcome)
    df <- df |> mutate(outcome = log(outcome - min_val + 1))
  } else if (transform_method == "standardized") {
    df <- df |> mutate(outcome = scale(outcome)[,1])
  }
  
  return(df)
}

# Funzione per eseguire l'analisi
run_analysis <- function(data, covariate_set) {
  formula <- switch(covariate_set,
    "none" = outcome ~ condition,
    "age" = outcome ~ condition + age,
    "age_gender" = outcome ~ condition + age + gender,
    "all" = outcome ~ condition + age + gender + education
  )
  
  model <- lm(formula, data = data)
  
  # Estrai coefficiente del treatment
  tidy_model <- tidy(model, conf.int = TRUE)
  treatment_row <- tidy_model |> filter(term == "conditiontreatment")
  
  if (nrow(treatment_row) == 0) return(NULL)
  
  tibble(
    estimate = treatment_row$estimate,
    std_error = treatment_row$std.error,
    p_value = treatment_row$p.value,
    conf_low = treatment_row$conf.low,
    conf_high = treatment_row$conf.high,
    n_used = nrow(data)
  )
}
```

## Lo Studio di Gould et al. (2025)

Le nostre simulazioni replicano, su scala ridotta, ciò che @gould2025same hanno trovato con dati reali:

**Nel loro studio:**

- 174 team hanno analizzato 2 dataset ecologici
- Le stime variavano da fortemente negative a positive
- Né la selezione di variabili né il peer review correlavano con l'accuratezza
- La variabilità **superava** l'errore statistico atteso

**Nelle nostre simulazioni:**

- 72 analisi dello stesso dataset producono stime da negative a positive
- Scelte "ragionevoli" portano a conclusioni opposte
- L'effetto vero (d = 0.25) cade all'interno della distribuzione, ma non al centro

Questo conferma che la fragilità metodologica non è specifica della psicologia, ma riguarda tutte le scienze empiriche dove i dati richiedono interpretazione.

## Riflessioni Conclusive

Le simulazioni di questo capitolo dimostrano che:

1. **Lo spazio analitico è vasto**: Anche con poche decisioni, esistono decine di analisi possibili.
2. **Scelte ragionevoli divergono**: Ricercatori competenti, usando metodi giustificabili, arrivano a conclusioni opposte.
3. **Alcune scelte pesano più di altre**: La gestione degli outlier e le trasformazioni hanno spesso l'impatto maggiore.
4. **La pre-registrazione aiuta ma non basta**: Fissa una traiettoria, ma non garantisce che sia quella "giusta".
5. **Il multiverse aumenta la trasparenza**: Mostrare l'intera distribuzione delle conclusioni possibili è più onesto di un singolo risultato.

::: {.callout-important title="Esercizio 1: Espandere il multiverse" collapse="true"}

Aggiungi una nuova dimensione al multiverse: la scelta del test statistico (t-test vs Mann-Whitney vs regressione robusta). Come cambia la distribuzione delle stime?
:::

::: {.callout-tip title="Soluzione Esercizio 1" collapse="true"}

```{r}
# Funzione per diversi test
run_analysis_extended <- function(data, test_type) {
  control <- data |> filter(condition == "control") |> pull(outcome)
  treatment <- data |> filter(condition == "treatment") |> pull(outcome)
  
  if (test_type == "t_test") {
    test <- t.test(treatment, control)
    tibble(
      estimate = diff(test$estimate),
      p_value = test$p.value
    )
  } else if (test_type == "mann_whitney") {
    test <- wilcox.test(treatment, control, conf.int = TRUE)
    tibble(
      estimate = test$estimate,
      p_value = test$p.value
    )
  } else if (test_type == "robust_regression") {
    # Regressione con errori robusti (approssimazione)
    model <- lm(outcome ~ condition, data = data)
    coef_summary <- summary(model)$coefficients
    tibble(
      estimate = coef_summary[2, 1],
      p_value = coef_summary[2, 4]
    )
  }
}

# Espandi il multiverse
test_types <- c("t_test", "mann_whitney", "robust_regression")

extended_multiverse <- expand_grid(
  outlier = c("keep", "remove_3sd"),
  test_type = test_types
) |>
  rowwise() |>
  mutate(
    prepared_data = list(prepare_data(dataset, outlier, "listwise", "raw")),
    results = list(run_analysis_extended(prepared_data, test_type))
  ) |>
  unnest(results) |>
  ungroup()

extended_multiverse |>
  group_by(test_type) |>
  summarise(
    `Media stima` = sprintf("%.2f", mean(estimate)),
    `Range p` = sprintf("[%.3f, %.3f]", min(p_value), max(p_value)),
    .groups = "drop"
  ) |>
```
